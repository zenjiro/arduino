# 1-ultrasonic-servo

## 動作の概要

超音波センサーで距離を測り、10 cm未満ならサーボを60度、それ以外なら120度に動かします。測定は約0.1秒ごとに繰り返します。

距離計測がタイムアウトすると距離は0として扱われるため、サーボは60度になります。

## 配線

| 部品 | Magic I/O Shieldのポート | 接続 |
| --- | --- | --- |
| 超音波センサーのTrig | `D7` | Trigを`D7`へ |
| 超音波センサーのEcho | `D8` | Echoを`D8`へ |
| 超音波センサーの電源 | `5V`、`GND` | センサーの電源、GNDへ |
| サーボモーター | `D9` | 信号線を`D9`へ、電源線を`5V`へ、GND線を`GND`へ |

シールド上のデジタル端子ソケットは、基板に印字された`D7`、`D8`、`D9`に合わせて接続してください。専用の超音波センサーソケットを使う場合も、Trigが`D7`、Echoが`D8`に接続されることを確認してください。サーボの電流がArduinoやUSBの供給能力を超える場合は、外部電源を使い、Arduinoと電源のGNDを共通にしてください。
