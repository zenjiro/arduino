# 4-car-c

## 動作の概要

C++で整理したロボットカー制御スケッチです。赤外線リモコンまたはボタンで走行・停止を切り替え、数字の「0」で停止、「1」「2」「3」で低・中・最高速度を選びます。OKボタンと走行切替ボタンは現在の速度設定を保ったまま走行・停止を切り替えます。停止中に「↑」を押すと最低速度で走り始め、「↓」で速度を下げ、最低速度のときにもう一度「↓」を押すと停止します。停止中も速度設定は保持されます。左右キーまたは「4」「5」「6」でステアリング用サーボの角度を調整でき、停止中もステアリングを操作できます。対応するmBlockプロジェクトは同じフォルダーの`4-car-c.mblock`です。

超音波センサーが障害物を検知すると、20 cm未満から減速し、5 cm以下でモーターを停止します。D4のボタンは押すとLOWになる接続を想定しています。走行・停止にかかわらず、サーボは最後に指定した角度を保ちます。

## 配線

| 部品・信号 | Magic I/O Shieldのポート | 接続 |
| --- | --- | --- |
| ステアリング用サーボ | `D2` | 信号線を`D2`へ、電源線を`5V`へ、GND線を`GND`へ |
| 走行切替ボタン | `D4` | ボタンを`D4`と`GND`の間に接続し、`D4`を外付けプルアップ抵抗（例: 10 kΩ）で`5V`へ接続 |
| モーター速度制御（PWM） | `D5` | モータードライバーの速度/PWM入力へ |
| 超音波センサーのTrig | `D7` | Trigを`D7`へ |
| 超音波センサーのEcho | `D8` | Echoを`D8`へ |
| 赤外線受信モジュール | `D10` | 信号線を`D10`へ、電源線を`5V`へ、GND線を`GND`へ |
| モーター方向制御1 | `D11` | モータードライバーの方向入力1へ |
| モーター方向制御2 | `D12` | モータードライバーの方向入力2へ |
| モーター、センサー、サーボの電源 | `5V`、`GND` | 各モジュールの電源仕様に合わせて接続 |

シールド上のデジタル端子ソケットは、基板に印字された`D2`、`D4`、`D5`、`D7`、`D8`、`D10`、`D11`、`D12`に合わせて接続してください。D5・D11・D12はモータードライバーを制御する信号線です。DCモーターをこれらのデジタル端子へ直接つながず、モーターはドライバーのモーター出力端子へ接続してください。Magic I/O Shield内蔵ドライバーを使う場合は、対象のモーター出力がこのスケッチの速度・方向制御信号に対応していることを確認してください。

このスケッチはD4を`INPUT`として読み取るため、押したときにLOWとなり、離したときにHIGHとなるよう外付けのプルアップ回路が必要です。サーボやモーターの電流がArduinoやUSBの供給能力を超える場合は、適切な外部電源を使い、GNDを共通にしてください。
