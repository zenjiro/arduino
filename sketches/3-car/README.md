# 3-car

## 動作の概要

赤外線リモコンまたはボタンで走行・停止を切り替えるロボットカーのスケッチです。数字の「0」で停止、「1」「2」「3」で低・中・最高速度を選び、上下キーで速度を調整します。左右キーまたは「4」「5」「6」でステアリング用サーボの角度を変えます。

赤外線受信モジュールは`D10`を使用します。

超音波センサーが障害物を検知すると、20 cm未満から減速し、5 cm以下でモーターを停止します。D4のボタンは押すとLOWになる接続を想定しています。停止中はサーボを90度に戻します。

## 配線

| 部品・信号 | Magic I/O Shieldのポート | 接続 |
| --- | --- | --- |
| ステアリング用サーボ | `D2` | 信号線を`D2`へ、電源線を`5V`へ、GND線を`GND`へ |
| 走行切替ボタン | `D4` | ボタンを`D4`と`GND`の間に接続し、`D4`を外付けプルアップ抵抗（例: 10 kΩ）で`5V`へ接続 |
| モーター速度制御（PWM） | `D5` | スケッチが使う制御ピン。シールド装着時は追加配線不要 |
| 超音波センサーのTrig | `D7` | Trigを`D7`へ |
| 超音波センサーのEcho | `D8` | Echoを`D8`へ |
| 赤外線受信モジュール | `D10` | 信号線を`D10`へ、電源線を`5V`へ、GND線を`GND`へ |
| モーター方向制御1 | `D11` | スケッチが使う制御ピン。シールド装着時は追加配線不要 |
| モーター方向制御2 | `D12` | スケッチが使う制御ピン。シールド装着時は追加配線不要 |
| 車体のDCモーター | `L1` | モーターの2本のリード線をシールドの`L1`モーター端子へ接続 |
| モーター、センサー、サーボの電源 | `5V`、`GND` | 各モジュールの電源仕様に合わせて接続 |

`D5`・`D11`・`D12`はスケッチがモータードライバー制御に使うArduinoのピン番号で、モーターやドライバー入力への外部配線は不要です。DCモーターの2本のリード線だけをシールドの`L1`モーター端子へ接続してください。

このスケッチはD4を`INPUT`として読み取るため、押したときにLOWとなり、離したときにHIGHとなるよう外付けのプルアップ回路が必要です。サーボやモーターの電流がArduinoやUSBの供給能力を超える場合は、適切な外部電源を使い、GNDを共通にしてください。
