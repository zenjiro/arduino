# 2-swing

## 動作の概要

赤外線リモコンでサーボモーターを操作します。「OK」ボタンで0度から180度の間を往復する動作を開始・停止し、数字の「1」「2」「3」でそれぞれ0度、90度、180度に移動します。スイング中は約20 msごとに角度を2度ずつ変えます。

使用するキーは「1」「2」「3」「OK」で、それぞれ`0x45`、`0x46`、`0x47`、`0x1C`です。これらは同梱リモコンで実測したIRremoteのコマンド値です。この例では他のキーを操作に使いません。別のリモコンでは値が異なる場合があります。

長押しによる赤外線のリピート信号は無視し、各ボタンの最初の受信だけを処理します。

赤外線受信モジュールは`D7`を使用します。

## 配線

| 部品 | Magic I/O Shieldのポート | 接続 |
| --- | --- | --- |
| サーボモーター | `D2` | 信号線を`D2`へ、電源線を`5V`へ、GND線を`GND`へ |
| 赤外線受信モジュール | `D7` | 信号線を`D7`へ、電源線を`5V`へ、GND線を`GND`へ |

シールド上のデジタル端子ソケットは、基板に印字された`D2`、`D7`のポート名に合わせて接続してください。サーボの電流がArduinoやUSBの供給能力を超える場合は、外部電源を使い、Arduinoと電源のGNDを共通にしてください。
